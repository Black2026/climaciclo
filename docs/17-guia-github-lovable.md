## Fluxo geral
No Lovable, acessar Projeto/GitHub ou Configurações → Git/GitHub, autorizar conta e conectar. O Lovable gera repositório e faz sincronização de mudanças. O GitHub App deve ter somente o acesso necessário à conta e aos repositórios selecionados.

## Condutas de segurança
Conferir permissões em GitHub → Settings → Applications/Installations; não autorizar todos os repositórios desnecessariamente; não salvar tokens ou segredos em Markdown ou commits; revisar o conteúdo antes de tornar público.

## Documentação
Os arquivos `docs/` documentam projeto, planejamento e testes, e `evidencias/` armazena capturas reais. Não alterar `src/`, dependências, migrações ou configs geradas pelo Lovable ao publicar documentação.
