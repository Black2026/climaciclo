# 12 — Prompt de planejamento usado para orientar o Lovable

> Registro da intenção de planejamento em **Plan mode**. Não solicitar build sem revisão.

```text
Atue como arquiteto de software, product manager, especialista em UX e segurança.

Planeje o MVP ClimaCiclo: "Seu ar em dia. Sua rotina mais leve."
Landing page em português com CTA "Montar meu acompanhamento", FAQ e explicação em três passos.
Configurador com três etapas: aparelhos, localização/interesse, dados de contato/revisão/consentimento.
Lovable Cloud para persistência e autenticação; server functions com validação Zod.
Página de confirmação com código. WhatsApp comercial somente se número configurado, e mensagem sem PII.
Painel administrativo protegido: leads, clientes, conversão, ordens, lembretes, configurações e indicadores reais.
Exigir papel admin no servidor, RLS, credenciais seguras e ausência de dados pessoais públicos.
Identidade visual #0F172A, #0D9488, #14B8A6 e #F8FAFC; mobile-first; ícones vetoriais.
Sem pagamentos, IA no aplicativo, chatbots, Stripe, Resend ou n8n.
Apresente arquitetura, rotas, dados, riscos, critérios de aceite e gates G1–G5.
NÃO implemente ainda. Retorne o plano para aprovação.
```

O plano do Lovable foi submetido a uma revisão de segurança e evoluiu para a [revisão 2](15-plano-lovable-revisao-2.md). O prompt acima é uma síntese documental do objetivo, e não log literal de toda a interação.
